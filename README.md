# 파이브골드 홈페이지 사용 안내

최신 버전: v8 · 2026년 10월 12일 · PC·모바일 최종 가독성 검토

전체 화면 영상, 큰 FIVEGOLD 타이틀, 한글 철학, 서로 다른 크기의 제품·착용·매장 사진을 중심으로 다섯 페이지를 다시 디자인했습니다. 한글은 Wanted Sans, 영문 제목과 숫자는 Manrope 기반의 로컬 웹 글꼴을 사용합니다. 이전 명조·세리프 중심 구성은 최신 화면에 적용하지 않습니다.

## 화면 열기

1. ZIP을 받았다면 파일을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택합니다.
2. 압축을 푼 폴더에서 **dist → index.html**을 더블 클릭합니다. Chrome 또는 Edge에서 열어주세요.
3. 이미 열려 있는 화면은 **Ctrl+R**로 새로고침합니다.
4. 모바일 메뉴는 오른쪽 위 두 줄 버튼으로 엽니다.
5. **제품**에서 검색·품목·정렬·페이지 번호를 이용하고, 사진을 누르면 상세와 확대 보기가 열립니다.

별도 설치·로그인 없이 열립니다. dist와 assets를 함께 유지하세요. 압축을 풀지 않고 index.html만 열면 사진이 나오지 않을 수 있습니다. 브라우저가 자동 재생을 제한하면 포스터를 표시합니다.

## 최신 구성

- 홈·브랜드·제품·룩북·매장 안내의 다섯 페이지.
- 전체 화면 무음 반복 영상, 별도로 등장하는 한글 철학과 큰 영문 브랜드 이름. 히어로 컬렉션 버튼·일시정지 버튼·한글 사명 보조 표기는 제거한 상태입니다.
- 밝은 금색 장식 대신 먹빛 바탕과 은빛 글자를 사용하고 금색은 주얼리 사진에 집중했습니다.
- PC 내비게이션과 제품 품목 드롭다운, 모바일 오른쪽 메뉴 드로어, 현재 페이지 표시와 내부 페이지 브레드크럼.
- 제품은 4개 품목·총 24개. PC 왼쪽 품목 메뉴, 모바일 품목 선택 바텀 시트, 한글·영문 제품명 검색, 가격·제품명 정렬, 한 페이지 12개씩 표시.
- 목록과 상세에 동일한 원화 임시 가격을 표시합니다. 제품 페이지·상세의 문의 버튼과 AI 디자인 설명은 없습니다. 임시 가격임을 알리는 작은 문구만 표시합니다.
- 상세창 확대·닫기·Esc·이전 버튼으로 초점 복귀. 짧은 모바일 화면에서도 닫기 버튼이 유지됩니다.
- 사진과 글의 스크롤 등장 효과, 지원하는 HTTP 브라우저에서 페이지 전환 효과. 동작 줄이기 설정에서는 정적인 포스터와 보이는 본문을 사용합니다.

토스트·설정 토글·슬라이더·개인정보 입력 폼은 현재 방문자가 수행할 작업과 연결되지 않아 넣지 않았습니다. 검색 필드에는 별도 레이블이 있고, 플레이스홀더는 입력 예시로만 사용합니다. 상세 사양은 별도 페이지가 아닌 현재 화면의 모달로 표시합니다.

## 운영 전에 전달할 정보

사진과 제품·모델·매장 설명은 콘셉트 시안입니다. 임시 가격은 사용자 승인에 따라 490,000원–2,190,000원으로 구성했습니다. 제품의 실제 소재·사양·가격을 보증하지 않습니다. AI 제작 기록은 ASSET-PROMPTS.json에 보존했습니다.

실제 판매 제품 사진·이름·소재·사양·가격, 공식 브랜드 소개와 로고, 매장 주소·영업시간·전화번호·카카오톡 채널 주소를 전달해 주세요. 사용자가 코드를 직접 수정할 필요는 없습니다.

매장과 헤더의 문의 버튼은 현재 안내창을 표시하며 실제 연락을 발신하지 않습니다. 지도도 실제 주소 확인 후 연결합니다. 회원가입·장바구니·결제·관리자·문의 양식·개인정보 수집 기능은 포함하지 않습니다. 검색 노출 방지용 noindex 설정이 유지되며, 온라인 공개는 진행하지 않았습니다.

## 포함 파일과 확인 결과

- dist의 HTML 5개, styles.css, app.js, data.js, favicon.svg 및 assets: 홈페이지 실행 파일.
- PRD.md: 최신 확정 요구사항.
- 최종디자인검토.md: 최신 PC·모바일 검토와 남은 확인 사항.
- 시네마틱디자인검토.md: 이전 v7 재디자인 검토 기록.
- POLISH-CHECKS.json / POLISH-TOUCH-CHECKS.json / POLISH-SOURCE-CHECKS.json: 최신 검사 기록.
- CINEMATIC-CHECKS.json / CINEMATIC-SOURCE-CHECKS.json: 이전 v7 검사 기록.
- DESIGN.md / design.json: 실제 화면에서 추출한 색상·서체·배치 규칙.
- ASSET-PROMPTS.json / CINEMATIC-REDESIGN.json: 제작 기록과 이번 수정 정보.

60개 배치 조건과 제품·메뉴 동작 검사를 통과했습니다. 다섯 페이지 PC·모바일 및 제품 상세창의 자동 접근성 검사에서 검출 위반은 없었습니다. 자동 검사는 접근성 인증이나 모든 기기의 정상 동작을 보증하지 않습니다. 실제 iPhone Safari와 사용자 기기의 영상 재생 확인은 공개 전에 필요합니다.

## 미디어·글꼴·비용·공개 상태

28개 WebP와 두 영상, 현재 사용하는 웹 글꼴 두 개를 ZIP에 포함했습니다. 작업 폴더의 원본 PNG와 이전 글꼴은 보관하고 ZIP에서는 제외했습니다. 이미지 56개의 해독된 픽셀과 제품 data.js, 최초 히어로 영상 원본은 수정 전과 동일합니다. 이미지에는 기존 제작 문구·출처만 메타데이터로 넣었습니다.

히어로 영상은 이전에 승인한 Higgsfield 56크레딧으로 제작한 영상입니다. 이번 재디자인의 추가 유료 생성·서비스 비용은 0입니다. 표시용 1080p 영상은 720p 원본을 확대·선명도 보정했으며 원본의 초점·해상도 한계가 남습니다. 새 영상 생성은 별도 작업입니다.

글꼴 두 개는 SIL Open Font License에 따라 웹용으로 추리고 이름을 변경했습니다. 라이선스와 저작권 고지는 assets/licenses에 있습니다. Wanted Sans는 한글 완성형과 자모를 지원하여 제품 검색에서 임의의 한글도 표시합니다. 원본: [Wanted Sans](https://github.com/wanteddev/wanted-sans), [Manrope](https://github.com/googlefonts/manrope).

Git 원격 저장소는 [hyun-pixel/Homepage_Jewelry](https://github.com/hyun-pixel/Homepage_Jewelry)이며 기본 브랜치는 main입니다. 이전 검토 기록의 Git 미연결·푸시 미실행 상태는 각 검토 당시의 상태입니다. 최신 커밋은 GitHub 기록으로 확인할 수 있습니다. 호스팅과 도메인은 연결하지 않았으며 공개 승인과 서비스 선택 시 비용을 안내합니다. 이전 화면·문서는 작업 폴더의 work/cinematic-v7-before와 v6 ZIP에 보관했습니다.

## v8 가독성 보완

모바일 제품명·가격과 영문명·정렬 글자를 키우고, 매장 안내의 글자 중간 끊김과 작은 태블릿 배치를 보완했습니다. 작은 세로 화면에서도 히어로 타이틀·하단 안내를 함께 볼 수 있습니다. 사진과 기능은 유지했습니다. 자세한 결과는 최종디자인검토.md를 확인해주세요.

## 저장소 구성

실행 파일은 dist 폴더에 있습니다. 소스를 받으면 dist/index.html을 열어 확인할 수 있습니다. 비밀정보·도구 설치 파일·원본 PNG·사용하지 않는 이전 글꼴은 커밋 대상에서 제외했습니다. GitHub 저장소에 보관하는 것과 웹사이트 호스팅은 별개의 작업이며, 온라인 배포는 아직 진행하지 않았습니다.
